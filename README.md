# Yournix

Простое приложение для Android: две вкладки, «Шифрование» и «Расшифровка».
Вставляете текст, результат появляется сразу, кнопка «Копировать» кладёт его в буфер обмена.

Шифр: матричный шифр Хилла для русского алфавита (33 буквы, арифметика по модулю 33, блок 3×3).

## Как получить APK

1. На github.com нажмите **New repository**, назовите его, например, `Yournix`. Лучше **Public**: тогда ссылка на APK открывается где угодно.
2. Распакуйте архив. Затем **Add file → Upload files** и перетащите **содержимое** папки `Yournix` (а не саму папку и не zip). **Commit changes**.
3. Проверьте, что в репозитории есть файл `.github/workflows/build.yml`. Папки с точкой в начале иногда не загружаются.
   Если файла нет: **Add file → Create new file**, в поле имени введите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` и нажмите **Commit**.
4. Откройте вкладку **Actions**. Сборка «Build APK» запускается сама и занимает 4–7 минут.
5. Когда появится зелёная галочка, на главной странице репозитория справа откройте **Releases** и скачайте `Yournix.apk`.
   Постоянная ссылка на свежий APK:
   `https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ/releases/latest/download/Yournix.apk`
6. Откройте APK на телефоне, разрешите установку из этого источника и нажмите «Установить». Нужен Android 8.0 или новее.

Каждый новый коммит в репозиторий запускает новую сборку и новый релиз. Новая версия ставится поверх старой.

### Если что-то пошло не так

- **Красный крестик в Actions.** Откройте упавший запуск и скопируйте последние строки ошибки.
- **Ошибка на шаге «Publish release».** Откройте Settings → Actions → General → Workflow permissions, выберите «Read and write permissions», сохраните и перезапустите сборку. APK при этом всё равно лежит в самом запуске, в разделе Artifacts.

## Как работает шифр

- Шифруются только русские буквы. Регистр сохраняется. Пробелы, знаки, цифры и другие символы остаются на своих местах.
- К тексту добавляется 1–3 служебные буквы (дополнение до целого блока, как в PKCS#7), поэтому шифротекст на 1–3 буквы длиннее. При расшифровке они убираются сами.
- Расшифровать можно только шифротекст целиком, без правок: иначе приложение покажет ошибку, а не мусор.
- Ключ зашит в `app/src/main/java/com/yournix/app/HillCipher.java` (`DEFAULT_KEY`):

  ```
  2 1 5
  1 3 4
  5 2 1
  ```

  Определитель −56 ≡ 10 (mod 33), НОД(10, 33) = 1, поэтому ключ обратим. Чтобы сменить ключ, замените числа так, чтобы НОД(det, 33) = 1. Обратную матрицу программа найдёт сама.
- Это учебный шифр. Он линейный и вскрывается по известному фрагменту текста, так что для настоящих секретов не годится.

## Подпись приложения

Постоянный ключ подписи лежит в `keystore/yournix.p12.b64` (пароль `yournix`). Он нужен только для того, чтобы обновления ставились поверх старой версии. Раз ключ публичный, подписать APK им может кто угодно. Для личного приложения это нормально; если важно, создайте свой ключ и замените файл.
